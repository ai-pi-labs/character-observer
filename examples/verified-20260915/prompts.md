# 完整输入与实际生图提示词

本文件保留实际送入内置 `image_gen.imagegen` 的文本。只传入单张图像所需的中性场景描述，没有传送 SKILL 全文。参考图均通过 `referenced_image_paths` 实际传入。

## 01-smartphone

### 技能输入

```text
$character-observer 角色="28岁原创成年城市旅人，女性，黑色微卷短发，海军蓝工装外套、米白圆领上衣、卡其长裤、白色运动鞋，深绿色帆布包"
mode=smartphone n=1 style=写实 scene=咖啡店门外 ar=3:4 discovered=off continuity=same-character 只要提示词。
```

### 首轮实际提示词

```text
经同意摆拍的虚构手机生活记录照，人物是28岁原创成年城市旅人，女性，成年外观，黑色微卷短发，海军蓝工装外套、米白圆领上衣、卡其长裤、白色运动鞋，完整着装，肩背深绿色帆布包。她刚从公共咖啡店走出来，右手接过纸杯，左手将包带往肩上提，目光看着画面外的店员。胸部高度的28mm等效手机视角，3:4竖幅，画面约倾斜2度，主体偏左，右边留下店门和一截成年行人的肩膀，肩膀占约8%，不挡住主角脸部。阴天散射光，轻微手机HDR与杯盖高光溢出，spontaneous snapshot，动作自然，面部清晰，衣料、皮肤和头发有真实纹理，没有正式摆姿，也没有看镜头，无界面文字、无水印、无真实品牌。这是一张写实摄影风格的生成图，不是拼图。
```

### 期望

- 仅一张3:4竖幅图；明确成年原创角色完整着装
- 手机近距离日常视角，主角偏左，轻微不齐整构图
- 纸杯与提包带两个动作可读，面部不被前景遮挡
- 角色不看镜头，无画面文字或品牌

## 02-reflection

### 技能输入

```text
$character-observer 使用01-smartphone实际成图作为角色参考，保持成年原创角色的发型、服装配色、帆布包。
mode=reflection n=1 style=写实 scene=公开商业街橱窗 ar=3:4 discovered=on continuity=same-character 只要提示词。
```

### 首轮实际提示词

```text
生成一张3:4竖幅的写实摄影风格图像。参考图只用于同一位原创成年女性角色的外貌、黑色微卷短发、海军蓝工装外套、米白圆领上衣、卡其长裤、白色运动鞋和深绿色帆布包，不沿用参考图的姿态、纸杯、咖啡店和构图。经同意摆拍的虚构橱窗反射摄影：28岁原创成年城市旅人，成年外观，完整着装。摄影者与人物站在同一片公开人行道上，从侧向约45度观察大块商店玻璃，以70mm等效镜头拍摄；人物主要出现在玻璃反射中，直接视野里不再重复出现第二个人物。她整理包带时从反射里察觉摄影者，眼睛轻轻转向镜中相机所在方向。窗框占左侧约15%，她的反射位于右侧中景，背景是同侧街道倒影，玻璃后无品牌陈列若隐若现。阴天柔光、轻微双层玻璃重影，反射面部仍清楚，reflection photography，皮肤、布料与玻璃有自然纹理；无文字水印，不透视到私密空间。只输出一张完整照片风格图像，不做拼图。
```

### 期望

- 第一张实际成图作为reference传入；主要角色外形服装相近
- 角色仅通过橱窗反射出现，不生成左右重复的第二个人物
- 窗框、街道倒影、玻璃后陈列可区分，反射关系合理
- 面部可读，整理包带与注意镜头的微小反应可观察

### 实际定向修正提示词

参考图顺序：`02-reflection-v1.png` 为待修图，`01-smartphone.png` 为角色参考。

```text
这是对参考图1的定向修图，只修正橱窗反射的空间表达。参考图1是待修改图，参考图2仅是原创成年女性的外貌与服装参考。保持28岁原创成年女性、黑色微卷短发、海军蓝工装外套、米白上衣、卡其长裤、白鞋、深绿色包、整理肩带的动作、自然成年外观和3:4竖幅，完整着装，虚构知情摆拍。把画面明确变成摄影者站在室外人行道上、以很斜的侧向角度拍摄一整面店铺反光玻璃：摄影机沿着建筑外墙观察，左侧必须看见商店外墙和一条退向远处的窗边，窗玻璃面作为清晰可见的平面占主体；女子本体在摄影者同一侧、位于画面之外，只让她的镜像出现在玻璃表面中，不出现她的第二个直接身影，也不能像摄影者在室内隔着玻璃拍外面的女子。反光玻璃同时映出与女子同侧的街树、对街立面；玻璃背后陈列很暗，仅隐约可见一件陶器，避免透明展示柜占据画面。女子的镜像依旧在画面右侧，看向反射中的摄影者方向，脸部清楚但带轻微玻璃重影，成像写实。不要新增文字、镜面箭头、拼图或示意图。
```

## 03-architecture-frame

### 技能输入

```text
$character-observer 使用01-smartphone实际成图作为角色参考，保持成年原创角色的发型、服装配色、帆布包。
mode=architecture-frame n=1 style=写实 scene=公共拱廊 ar=3:4 discovered=off continuity=same-character 只要提示词。
```

### 首轮实际提示词

```text
生成一张3:4竖幅的写实摄影风格图像。参考图只用于同一位原创成年女性角色的外貌、黑色微卷短发、海军蓝工装外套、米白圆领上衣、卡其长裤、白色运动鞋和深绿色帆布包，不沿用参考图的姿态、纸杯、咖啡店和构图。经同意摆拍的虚构城市观察摄影：28岁原创成年城市旅人，成年外观，完整着装，肩背深绿色帆布包。她正在公共拱廊远端停步查看无文字的图形导览牌，身体稍侧，脸部轮廓可辨。摄影者在对面拱门外，以平视70mm等效镜头把她纳入门洞，3:4竖幅，前景石质拱门和两侧立柱约占画面30%，结构边缘清晰，frame within a frame。人物约占画面高度30%，偏右，左侧留出廊道纵深；廊下阴影与外侧柔和日光有自然明暗差，仅保留少量颗粒，石材和衣服有真实纹理。她看导览牌，没有发现镜头。不要用虚化叶片替代建筑框架，不出现可读文字、真实品牌或水印。只输出一张完整照片风格图像，不做拼图。
```

### 期望

- 第一张实际成图作为reference传入；保持可识别的发型和服装配色
- 清晰的石拱门/立柱形成建筑框中框，而非叶片遮挡
- 人物约画高30%、偏右，公共廊道纵深保留
- 角色看导览牌不看镜头，远景身份细节不过度声称

### 实际定向修正提示词

参考图顺序：`03-architecture-frame-v1.png` 为待修图，`01-smartphone.png` 为角色参考。

```text

```
