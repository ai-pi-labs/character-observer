# 三种观察机位 · 实际生成案例

本次用 Character Observer 的现有规则，给同一位 28 岁原创成年城市旅人生成三种观察画面：手机随拍、橱窗反射、建筑框景。三张最终图均为 **1086 × 1448、3:4 竖幅**，保留图像工具返回的原始 PNG。

角色设定为成年虚构女性，黑色微卷短发，海军蓝工装外套、米白上衣、卡其长裤、白鞋与深绿色帆布包。场景分别是公共咖啡店门外、商业街橱窗和公共拱廊；图像是虚构摆拍风格，不是现实偷拍记录。

## 如何使用

1. 在 [完整提示词](prompts.md) 中选一个模式，将“技能输入”交给已经加载 Character Observer 的助手。
2. 也可以直接把该模式的完整摄影提示词复制到图像生成工具。这里的提示词保留实际调用原文，包含具体动作、场景、构图和避免项。
3. 想保留角色外形时，将 `01-smartphone.png` 作为参考图实际上传或传入工具。仅写文件名不能完成参考绑定。
4. 对照该模式的期望和下方观察结果，检查新的成图；不要把这组三张的结果套用为所有模式都已验证。

## 逐图观察

| 模式 | 这次看到的结果 | 保留的限制 |
| --- | --- | --- |
| `smartphone` | 接杯和提包带动作可读；主角偏左，右侧路人形成前景，脸部清楚，目光朝店员。采用首轮图。 | 28mm、2 度倾角和前景 8% 是提示描述，没有从图片中独立标定。帽沿有极小白色图形，未识别成真实品牌。 |
| `reflection` | 修正后，外侧人行道、退向远处的墙面和窗框可见；主角形象与街道倒影叠在玻璃中，没有再出现第二个直接身影。 | 首轮容易读成隔窗看人。最终图只做了视觉可信性核对，没有证明精确镜面光路或 45 度机位；人物表情与包带细节也有变化。 |
| `architecture-frame` | 清晰石柱、拱形边缘和连续廊道构成框中框；主角偏右看导览牌，画高占比由首轮约 45% 缩到约 32%。 | 比例为目视估算；拱顶仍贴近上缘，外弧略有裁边。远景面部不适合严格身份比对，70mm 未独立验证。 |

发型、服装配色和人物轮廓整体接近，不能据此声称三图身份完全一致。年龄是输入中的角色设定，图片复核只检查成年外观与完整着装。

## 本次执行与文件

这个技能由文本规则组成，没有需要运行的本地 CLI。本次在 Codex 中读取 `SKILL.md` 与模式案例，形成完整中文提示词后，使用内置 **`image_gen.imagegen`** 实际生成；每个资产各一次调用。共 3 次首轮生成、2 次定向修改。首图没有参考；后两张首轮均通过 `referenced_image_paths` 传入首图；修改时同时传入待修图与首图角色参考。

| 文件 | 用途 |
| --- | --- |
| [prompts.md](prompts.md) | 完整技能输入、首轮提示词、期望和两次实际修正提示词 |
| [cases.json](cases.json) | 来源文件指纹、实际工具输出文件名、参考顺序、尺寸与逐图记录 |
| [01-smartphone.png](01-smartphone.png) | 手机随拍最终图，同时是其他两图的角色参考 |
| [02-reflection.png](02-reflection.png) / [首轮](02-reflection-v1.png) | 橱窗反射最终图与首次结果 |
| [03-architecture-frame.png](03-architecture-frame.png) / [首轮](03-architecture-frame-v1.png) | 建筑框景最终图与首次结果 |

图像没有经过绘图代码拼接、裁剪或重绘。技能全文没有发往图像服务，只传入对应的具体场景提示词与已生成的角色参考。底层生成模型未在工具结构化结果中单独标注，本记录按实际使用的内置工具归档。

这是一轮 **3 / 19 模式**的代表性测试，不覆盖其余模式、联络表、多机位、批量上限或所有参数组合，也不保证换一个图像模型或重新调用时获得相同结果。
